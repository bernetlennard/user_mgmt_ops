  kubectl -n {{ .Release.Namespace }} get hpa,pdb
  kubectl -n {{ .Release.Namespace }} describe quota

TARGETS showing <unknown> means metrics-server is not answering, not that the load is
zero. A scale-out that never happens despite high cpu is usually the ResourceQuota, and it
says so on the ReplicaSet, not on the HPA:

  kubectl -n {{ .Release.Namespace }} describe rs -l app.kubernetes.io/component=backend | grep -i quota

Note that spec.replicas is intentionally absent from the backend Deployment while the HPA
is enabled -- that is what stops ArgoCD's selfHeal from reverting every scale-out.
{{- else -}}

values-prod.yaml / values-staging.yaml, not here.
